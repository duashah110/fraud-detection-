 ChainGuard – Blockchain Fraud Detection

ChainGuard is a blockchain fraud detection and transaction risk analysis system built with Python and Streamlit. It analyzes Solana and Ethereum transactions and provides a risk score, risk level, and transaction details.

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/duashah110/fraud-detection-.git

Go to the project folder:
cd fraud-detection-

Install the required dependencies:
pip install -r requirements.txt

Run the application:
streamlit run app.py
